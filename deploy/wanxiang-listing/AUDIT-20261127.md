### 排除的一个虚惊：i18n

全量扫描报 `i18n/index.js` 比基准少 94%，一度怀疑是重编译把已发布 i18n 打回 1140 键。
**实测排除**：主线 `src/i18n/index.ts` 是 re-export shim（`export * from '@jiuzhang/shell-renderer/i18n'`），
基准是内联实现。运行时对拍：

```
导出面 15/15 一致
zh-CN 基准 1392 键 / 主线 1392 键 → 缺 0 多 0 文案异 0
en-US 基准 1392 键 / 主线 1392 键 → 缺 0 多 0 文案异 0
```

**结论：i18n 完全等价，不是缺口。** 尺寸差是架构差（共享包 vs 内联）。
